## 프로젝트 소개
**ModuERP**는 조직 운영에 필요한 기능들을 모듈형으로 제공하는 ERP 웹 서비스입니다.  
업무 프로세스 일원화와 데이터 정합성 향상을 통해 기업 운영의 효율성을 높이는 것을 목표로 합니다.

## 프로젝트 의의
- **업무 프로세스 통합**: 여러 기능을 하나의 ERP 시스템으로 통합하여 업무 생산성 향상  
- **데이터 정합성 확보**: 엑셀 기반 데이터 업로드 시 유효성 검증을 통해 오류 최소화  
- **조직 운영 효율화**: 역할 기반 접근 제어 및 모듈형 구조로 유지보수 용이성 확보

## 차별점
ModuERP는 다른 ERP 시스템과의 차별점으로, 모듈식으로 기능을 선택하여 구매하고 사용할 수 있는 구조를 갖추고 있습니다. 이를 통해 사용자는 필요한 기능만을 효율적으로 이용할 수 있습니다.

## 담당 역할 (최은영)
ModuERP 전체 기능 중 다음 영역을 담당했습니다.

- 근태 문서 기능 개발  
  - 임시저장, 제출, 제출 취소  
  - 결재(승인/반려/취소) 프로세스 구현  

- 사내 이메일 UI/UX 개발  
  - 이메일 작성/조회 화면 구성  
  - 사용자 흐름을 고려한 간결한 인터페이스 설계  

- ERP 서비스 판매 페이지 개발  
  - 대표 회원가입  
  - 승인코드 자동 발급 기능  

- Excel 기반 조직 정보 업로드 기능 구현  
  - 부서/직원 데이터 파싱 및 유효성 검증  
  - Oracle DB 저장 로직 개발  

- 역할 기반 로그인 분기  
  - 대표/직원 권한에 따른 화면 이동 처리  

- 공지사항 CRUD 구현  

- 전체 UI 보완 및 front-end 기능 개선
